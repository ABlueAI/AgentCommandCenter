Transcript is the cheapest pass — no visual tokens, text analysis only. Video runs the full forensic visual analysis at the highest token cost, so it's a deliberate opt-in, not the default.

        

          
          

          

            
            
          

          

          
Each slice bills ONLY its own length. One slice = the existing single-range analysis. 2–8 slices run as ONE analysis of just those slices; they must be chronological and non-overlapping, and together may total at most 1800s (30 min) — that cap is fixed. Slices apply on the SDK/YouTube route only.

        

        
        
        

        
Transcript and audio automatically use Flash-Lite. Video automatically uses Pro, because bounded video analysis is where report quality matters most. Pick a model yourself and it stays selected until you close this window. Pro can use significantly more quota and cost more than the other options. Whether any run falls inside a free tier depends on your own Gemini project and account — this app cannot tell you that.

        
        
        
Media resolution is enforced for YouTube URLs in video mode (sent to the API directly — LOW cuts video tokens ~65%). For non-YouTube/local files the CLI fallback applies and the choice is recorded in the run log only (the installed Gemini CLI has no flag for it).
