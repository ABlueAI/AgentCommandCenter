# Test-suite audit

Reviewed `main` at `62888fc6a28b8bc7d67c3a325ab8a19313385f09`. Source locations refer to that commit. Each row records a baseline and a one-change experiment in a disposable checkout. The tests were unchanged. The production files were restored after each run. The result in each row applies to the named test or suite.

The audit covered top-level `app/*.test.js` and recursive `scripts/**/*.Tests.ps1`, including the PowerShell suites directly under `scripts/`. All 70 in-scope JavaScript suites have exactly one invocation in `app/package.json` and all 40 PowerShell suites match the runner's recursive discovery. Both entry points are wired into `.github/workflows/ci.yml`. The Node and Pester reachability tests passed locally with 6 and 4 checks respectively.

Mutation runs used Node 22.21.1 and PowerShell 7.4.19 with Pester 4.10.1 on Linux. The Windows CI job uses Windows PowerShell 5.1 and Pester 3.4. The SDK proof used a local provider stub.
