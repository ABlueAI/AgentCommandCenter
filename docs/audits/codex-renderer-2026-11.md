# Renderer audit · November 2026

Reviewed `app/renderer/` on `main` at `1136f88a8f470a45c5065f1eeacde25bfd62243e`. Findings were checked against the renderer and the IPC contracts it calls. Isolated Node probes confirmed nine of the observed behaviors.

| Severity | Finding | File and line | User impact | Fix idea |
| --- | --- | --- | --- | --- |
| high | Quick Links can overwrite saved links before loading them | `app/renderer/quick-links-view.js:140` | Manage is active while the initial load is pending. Saving the empty draft or adding a link from that draft can replace the entire saved list. | Enable editing and saving only after a successful list response has supplied the initial draft. |
| high | A settings write failure leaves the launch controls unwired | `app/renderer/app.js:1825` | Opening Mako with a settings file it cannot write stops startup before the app wires its controls. The window can still show controls that do nothing. | Wire the UI independently of the startup settings write and show a persistent error if saving the selected repository fails. |
| medium | Gemini Video Scout can launch the same run twice | `app/renderer/app.js:2620` | Two Create & Launch clicks before the key check returns can start two independent runs for the same video and consume provider quota twice. | Guard submission before the first await and release the guard on a visible refusal or completed handoff. |
| medium | A pending worktree launch can pick up options from the next dialog | `app/renderer/app.js:2744`, `app/renderer/app.js:2758` | Opening New Agent while an earlier worktree is being created can change which CLI the first agent launches or reset its Hard setting. | Capture the CLI and Hard setting with the submitted worktree request and use that snapshot for the launch. |
| medium | A failed session launch removes the recovery action | `app/renderer/app.js:1365`, `app/renderer/app.js:1374` | Resume removes the offer before the PTY acknowledges startup. Start fresh also dismisses the old session before the new one starts, so a failed launch can take away the in-app way to recover it. | Keep the offer until startup is acknowledged, then persist a Start fresh dismissal. |
| medium | Controlled-run allowance stays stale after the pane exits | `app/renderer/app.js:1573` | An exited or closed controlled pane can leave the toolbar showing a live binding and remaining turns even though main has closed the run. | Refresh the admission view after process exit and explicit pane close have updated main's run state. |
| medium | A successful controlled send can erase the next draft | `app/renderer/admission-view.js:306` | The prompt field stays editable while sending. If the user starts the next draft, success clears those new edits along with the submitted text. | Clear the field on success only if its edit revision still matches the submitted draft. |
| medium | Overlapping Library scans can replace newer results | `app/renderer/app.js:302` | Refresh remains clickable during a scan. An older scan that finishes last can replace the newer list, and an older failure can replace a newer success status. | Serialize scans per Library view and tie the visible list and status to the single active scan. |
| medium | PTY parsing retains every update to an unfinished line | `app/renderer/pty-parser.js:104` | A terminal that updates progress with carriage returns and no newlines makes the parser retain and rescan all the overwritten text. Long-running output can slow the renderer even with bounded xterm scrollback. | Bound the unfinished line and discard overwritten carriage-return segments as they arrive. |
| medium | Dictate accepts panes that cannot receive a transcript | `app/renderer/app.js:1737` | An exited terminal or Claude Video Scout's output-only pane can become the active target. Dictation records and transcribes, then the text disappears because the destination has no live PTY. | Track whether each pane accepts input, refuse invalid destinations before recording, and report if a destination becomes invalid before delivery. |
| medium | Read Aloud can hide Stop while earlier speech continues | `app/renderer/tts.js:138` | Reading a selection that cleans down to empty sets the status to idle while earlier audio continues playing, which hides Stop. | Report the empty selection without changing the active speech status or its Stop control. |
| medium | Video Scout log handling | | | |
| low | A pending Quick Links save discards later edits | `app/renderer/quick-links-view.js:202` | The editor remains active while Save is pending. A successful response closes it and discards changes made after the click. | Lock the editor during the save or retain any draft edits made after submission. |
| low | A failed Library refresh clears the question for the report still on screen | `app/renderer/app.js:291` | The failed scan leaves the report visible but erases the unsent question and hides Ask. The user has to reselect the report and retype the question. | Keep the existing report and follow-up state until a successful refresh replaces their source. |
| low | Closed panes accumulate in the status badge cache | `app/renderer/pane-status-badge.js:200` | The renderer retains status for closed pane IDs and revisits them on every Dockview layout change. Memory and layout work grow with the number of panes opened over a long session. | Forget closed pane IDs and ignore later status updates for panes that are no longer live. |
| low | A malformed Video Scout URL closes the dialog without an error | `app/renderer/app.js:2616`, `app/renderer/app.js:2687` | Input can pass the scheme check but fail URL parsing after the dialog has closed. Neither provider starts a pane, and the user gets no validation message. | Parse the URL before closing the dialog and show a field error if parsing fails. |
| low | The command palette can focus the wrong agent | `app/renderer/app.js:1431` | If the worktree list refreshes while the palette is open, an agent command still shows the old name but can focus a different card at the old position. | Resolve the selected worktree by its stable identity when the command runs and show a notice if it was removed. |
| low | Holding Ctrl+K repeatedly opens and closes the palette | `app/renderer/shell-nav.js:693` | Keyboard repeat toggles the palette and focus back and forth, so the final state depends on when the user releases the key. | Consume the shortcut but toggle only on the initial keydown. |
| low | The main checkout can appear as an agent | `app/renderer/app.js:1836` | Repositories whose primary checkout uses a branch such as `master` show that checkout among the agents. A linked worktree on a branch named `main` is hidden. | Exclude the selected primary checkout by its worktree identity instead of filtering by branch name. |
| low | Theme and speech settings can look saved after a write failure | `app/renderer/app.js:160`, `app/renderer/app.js:1783`, `app/renderer/app.js:1789` | Theme, voice and speed change immediately, but a rejected save has no user-facing error. The changes disappear on restart. | Check the save response and show which applied preference could not be saved. |
